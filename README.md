# 📌 Problem Overview

Land records are maintained across a wide variety of scanned, historical, regional-language and semi-structured documents.

Examples include:

- 7/12 records
- 8A records
- Mutation / Ferfar records
- Property records
- Historical land documents
- Scanned registers
- Legacy PDFs and images

The challenge is not only to extract text from these documents.

A useful digitization system must also determine:

```text
What is this document?
        ↓
What information does it contain?
        ↓
Which land parcel does it represent?
        ↓
Which fields are reliable?
        ↓
Do related records agree?
        ↓
Are there conflicts or inconsistencies?
        ↓
Does the record require human verification?
        ↓
Can the final decision be traced?
